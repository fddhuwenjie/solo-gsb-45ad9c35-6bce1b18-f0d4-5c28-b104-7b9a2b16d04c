# 会议室投影机选位工作台

基于 **Python Flask + 原生 JavaScript + SVG** 的 Web 工作台，用于在给定房间、幕布、镜头参数与禁装区时，计算并连续显示每个投影机镜头方案的可安装区域。

## 一键启动

```bash
docker compose up --build
```

启动后用浏览器访问：

**http://localhost:8000**

停止：在终端按 `Ctrl+C`，或执行 `docker compose down`。

## 本地直接运行（可选，不使用 Docker）

```bash
pip install -r requirements.txt
python app.py
```

同样访问 http://localhost:8000 。

## 功能说明

- **房间与幕布**：设置房间宽 / 进深 / 净高与墙面余量；设置幕布宽高、下沿离地高度，幕布可在顶视图直接拖动。
- **镜头方案**：录入投射比范围、水平/垂直镜头位移（±%）、机身宽深高；可添加多个方案。
- **禁装区**：点击「绘制禁装区」后在顶视图拖拽出矩形（如吊灯、横梁、空调、柱子），可拖动移动、拖右下角缩放、Delete 键删除。
- **可安装区域计算**：服务器对每个方案求以下约束的交集——
  1. 投射距离（`投射比 × 幕宽`）
  2. 镜头水平位移
  3. 墙面余量（机身矩形不越出四墙内缩余量）
  4. 机身避障（禁装区按机身尺寸膨胀后从交集中扣除，结果为若干不重叠矩形）
- **退化可行域（安装线）**：水平镜头位移为 0（或位移带被墙面余量夹成单点）时，镜头 x 坐标固定、可行域退化为一条纵深**安装线段**。线段长度大于 0 即可沿纵深安放机身，因此系统将其判为**可行**（面积为 0，另以 `line_length` 表示可行总长度），不再因面积为 0 误判为不可行。禁装区仍按机身尺寸膨胀：仅当膨胀后的 x 区间严格覆盖该固定 x 时，才把其 y 区间投影为纵深禁段从线段扣除；沿用与二维矩形一致的边界接触规则（仅边界接触不判碰撞），线段被完全覆盖时才给出避障无解诊断。顶视图中安装线以粗线段绘制，端点带刻度，并标注扣除障碍后的可行总长度。
- **即时重算**：拖动幕布、禁装区或安装点后自动重算（防抖 40ms）。
- **无解诊断**：交集为空时，明确指出是投射距离/水平位移/垂直位移/墙面余量/机身避障中哪些约束导致为空；避障场景会用“逐一移除恢复测试”点名覆盖区域的禁装区。
- **双视图同步**：
  - 顶视图：各方案可安装区域（含退化安装线段）、基础交集虚线框、最近/最远投射距离边界、禁装区、投射包络、机身占位、房间/幕布/选点尺寸标注。
  - 侧视图：幕布剖面、投射包络、投射距离×镜头高度可行域、全高禁装带、机身与镜头高度标注。
- **选点校验**：在顶视图单击或拖动选择镜头位置，侧视图可拖动调整镜头高度与投射距离；面板逐项显示投射距离、位移利用率、墙面余量、避障、镜头高度的 ✓/✗ 与数值。
- **方案排序**：可行方案始终排在不可行方案之前；同为可行时，普通二维区域按可安装面积降序排列在前，退化安装线按可行总长度降序排列在后；不可行方案标红并可悬停查看冲突原因。
- **内置示例**：右上角下拉可载入 3 个场景（标准会议室、小型培训室、含无解方案的报告厅），页面打开即自动载入第一个示例。

```

static/style.css
Dockerfile / docker-compose.yml
```

## 计算模型

顶视图坐标：原点为前墙左角，x 向右、y 由幕布墙指向后墙（米）。镜头位于机身前表面中央，机身占位矩形为 `[px-bw/2, px+bw/2] × [py, py+bd]`。方案可安装区域：

```
[投射距离带] ∩ [水平位移带] ∩ [墙面余量矩形] \ ⋃(禁装区按机身尺寸膨胀)
```

侧视图中镜头高度受 `幕布中心 ± 垂直位移×幕高` 与机身上下不穿出房间的交集约束。

退化情形：当 x 交集宽度为 0 而 y 区间长度大于 0 时，可行域为固定 x 的安装线。后端结果中 `domain` 取 `area`（二维区域）、`line`（安装线）或 `empty`（点/无交集），安装线以 `line_length`（米）给出扣除禁装区后的可行总长度而 `area` 为 0；二维计算与 `/api/compute`、`/api/examples` 的其余字段均保持兼容。
